Base de conocimiento del asistente (Grupo 5 – 5K10, PG3)

  Grupo_5_PG2_U1_carga.cypher      script de carga del grafo del PG2 (bloques 1 a 9)
  S1_PI4_complemento.cypher        sinónimos de aptitudes y marcadores de S1-R02 (PI4 de S1)
  Grupo_5_PG3_consultas.cypher     catálogo de las consultas que ejecuta el asistente (lectura y escritura)
  Grupo_5_PG2_U1_consultas.cypher  consultas del PG2, como referencia (opcional: copiar desde el Drive del PG2)
  Grupo_5_PG3_export.cypher        exportación del grafo completo (la genera --exportar)
  Grupo_5_PG3_export.json          lo mismo en JSON

Instalar desde cero (en este orden):

  python -m api.main --cargar neo4j/Grupo_5_PG2_U1_carga.cypher
  python -m api.main --cargar neo4j/S1_PI4_complemento.cypher
  python -m api.main --depurar --aplicar

O bien reconstruir el grafo exportado en una base vacía:

  python -m api.main --cargar neo4j/Grupo_5_PG3_export.cypher

Para generar la exportación (antes, borrar las vacantes de prueba):

  python -m api.main --limpiar --si
  python -m api.main --exportar

Todas las consultas que usa el asistente están en core/consultas.py (lectura y escritura
separadas; las de lectura se verifican sin cláusulas de escritura al arrancar).
